========================================
5. DESIGN CHOICE
================

Design choice:

The project separates HTTP delivery, use cases, repositories, and domain models.

Reason:

This separation keeps business logic independent from HTTP and database details.

Benefits:

* Easier unit testing.
* Clear responsibilities.
* Repository implementations can be replaced.
* HTTP handlers remain focused on request/response handling.
* The architecture can evolve without tightly coupling all layers.
